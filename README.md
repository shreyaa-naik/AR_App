# 📖 Project Overview

**Virtual Revival of Monuments of South Canara Region Using Augmented Reality** is an Augmented Reality (AR) application developed to digitally preserve and showcase historical monuments of the South Canara region.

The project uses photogrammetry to create detailed 3D models of monuments from drone-captured images. These models are optimized and integrated into an AR application, allowing users to visualize monuments interactively using their Android devices.

This project aims to promote cultural heritage, improve accessibility to historical sites, and provide an engaging educational experience through immersive AR technology.

---

# 🎯 Objectives

- Digitally preserve historical monuments.
- Create realistic 3D models using photogrammetry.
- Develop an interactive marker-based AR application.
- Promote awareness of South Canara's cultural heritage.
- Provide an educational platform for students, researchers, and tourists.

# 🚀 Installation

1. Clone the repository.

```bash
git clone https://github.com/shreyaa-naik/AR_App.git
```

2. Open the project using **Unity Hub**.

3. Install the required Unity packages and Vuforia Engine.

4. Build the project for Android.

5. Launch the application.

6. Scan the supported image target to visualize the 3D monument in Augmented Reality.
