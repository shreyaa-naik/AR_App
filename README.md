# 📖 Overview

The **Virtual Revival of Monuments of South Kannada Region Using Augmented Reality** project aims to digitally preserve historical monuments using **Photogrammetry** and **Augmented Reality (AR)**.

This project captures real-world monuments using drone photography, reconstructs them into detailed 3D models, optimizes the models, and visualizes them through an interactive Augmented Reality application developed using Unity and Vuforia.

---

# 🎯 Objectives

- Digitally preserve historical monuments.
- Generate accurate 3D models using photogrammetry.
- Visualize monuments in Augmented Reality.
- Promote cultural heritage through modern technology.
- Provide an interactive learning experience.

# 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/shreyaa-naik/AR_App.git
```

2. Open the project in Unity.

3. Install the required packages.

4. Build and deploy the project to an Android device.

5. Scan the AR marker to visualize the monument.
